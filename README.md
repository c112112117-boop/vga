# vga
使用 VHDL 設計 VGA 顯示畫面，解析度為 640x480，透過 VGA 輸出至螢幕，並使用 ZedBoard FPGA 開發板進行實作。

VGA 顯示：

畫面背景設定為黑色，並在螢幕上顯示三種不同顏色及形狀的圖形，分別為紅色正方形、綠色圓形以及藍色三角形，三個圖形由左至右排列。

VGA 時序：

使用 Clock Wizard 將 100MHz 輸入時脈轉換為 25MHz，作為 VGA 像素時脈。解析度設定為 640x480，並透過水平計數器（h_counter）與垂直計數器（v_counter）控制螢幕顯示位置。

圖形顯示：

透過 VHDL 判斷目前像素的 X、Y 座標，設定不同圖形的顯示範圍。紅色正方形使用座標範圍判斷，綠色圓形使用圓心與半徑計算，藍色三角形則利用座標關係判斷是否位於三角形內部。最後透過 12-bit RGB 輸出設定各圖形的顏色。

專案檔案：

vga_top.vhd：VGA 顯示頂層模組。

vga_sync.vhd：產生 VGA 水平與垂直同步訊號。

vga_color.vhd：控制三種顏色與圖形的顯示。
